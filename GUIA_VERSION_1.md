# Guía de la Versión 1 - Localidades

## ¿Qué hace esta versión?

Esta versión se enfoca en analizar localidades mexicanas. Es ideal para estudios demográficos y territoriales que necesitan información detallada sobre pueblos y ciudades.

## ¿Cuándo usarla?

- Cuando necesitas información específica sobre localidades mexicanas
- Para análisis demográficos y poblacionales
- Cuando quieres estudiar una sola área con detalle
- Para proyectos que requieren datos de población y características de localidades

## Cómo funciona

1. **Sube tu archivo KML**: Define el área que quieres estudiar
2. **Configura el buffer**: Elige si quieres analizar solo el área exacta o incluir una zona de influencia alrededor
3. **Realiza el análisis**: La herramienta busca todas las localidades dentro del área
4. **Explora los resultados**: Navega por el mapa y las listas de localidades encontradas

## Elementos que analiza

- **Localidades mexicanas**: Todos los pueblos y ciudades de México con sus datos demográficos
- **Información detallada**: Población total, por género, tipo de localidad (urbana/rural)
- **Códigos geoestadísticos**: CVEGEO para identificación única
- **Ubicación precisa**: Coordenadas exactas de cada localidad

## Características especiales

- **Buffer configurable**: Puedes definir una zona de influencia en metros alrededor de tu área
- **Navegación inteligente**: Haz clic en cualquier localidad para ir directamente a ella en el mapa
- **Etiquetas en el mapa**: Ve los códigos CVEGEO directamente sobre los puntos
- **Vista de área**: Regresa fácilmente a ver toda tu zona de estudio

## Resultados que obtienes

- Mapa interactivo con todas las localidades encontradas
- Lista organizada con información demográfica
- Estadísticas del área: superficie, población total, densidad
- Reporte Excel con todos los datos detallados
- Gráficos de población por localidades

## Ventajas

- Información muy detallada de localidades
- Análisis demográfico completo
- Navegación fácil entre elementos
- Configuración flexible del área de estudio

## Limitaciones

- Solo analiza localidades, no otros elementos geográficos
- Diseñada para una área a la vez
- No incluye temas indígenas específicos
